# High-Dimensional Data Analysis Using PCA and Clustering

## Case Study 48 — Machine Learning

### Overview

This project focuses on analyzing high-dimensional data using **Principal Component Analysis (PCA)** and **Clustering** techniques. PCA is used to reduce the dimensionality of the dataset, while clustering is used to identify natural groups within the data.

### Techniques Used

* Principal Component Analysis (PCA)
* K-Means Clustering
* Hierarchical Clustering
* Elbow Method
* Dendrogram
* Silhouette Score
* Exploratory Data Analysis (EDA)
* Feature Scaling

### Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Streamlit
* Jupyter Notebook

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```
